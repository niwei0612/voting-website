# 星选投票 — 公开评选投票平台

公开作品/活动评选投票网站。免注册、实时票数、多类型投票。

## 在线使用

https://niwei0612.github.io/voting-website/

## 特点

- 三种投票类型：单选 / 多选（限可选数）/ 评分（1-5星）
- 多媒体候选展示：封面图 + 简介 + 视频链接
- 实时公开票数与排名，透明展示
- 免注册即投，本地标记防重复投票
- 管理后台：活动创建、候选增删改、时间控制、数据统计
- 管理密码认证，密码可修改
- 移动端/PC 端自适应
- 活动热闹风格，全中文界面

## 演示数据说明

当前为演示模式：数据存储于浏览器 localStorage（含 3 个示例活动）。
管理后台初始密码：`admin123`

## 真实部署（接入云数据库）

数据层已抽象封装（DB 对象），将 localStorage 实现替换为 Firebase / LeanCloud / Supabase 即可实现全网票数实时共享，接口签名保持不变。

## 部署

单个 HTML 文件（index.html），可放任意静态服务器或本地打开。
